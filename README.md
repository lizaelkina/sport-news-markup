### Описание проекта

- Одностраничный, адаптивный сайт на Flexbox и Grid Layout.
- Библиотека "Swiper" для слайдеров.
- Библиотека Animate On Scroll для анимации таблицы при прокрутке страницы.

### Используемые технологии

- PUG
- SCSS
- JavaScript
- GULP
